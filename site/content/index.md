# Documentation

Welcome. Waggle Gate is a GitHub merge check for repos where AI agents write code. A keeper talks with their queen, and the queen writes each task's claim. The worker does not. These pages are the spec, the reference, and the recipes. New here? Start with the [quick start](/docs/quick-start/). The [landing page](/) is the short version.
