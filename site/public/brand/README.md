# Site brand assets

Curated Waggle and Walt assets for the public site, served from `/brand/`.

**Source:** Waggle identity kit (Walt) — the approved product identity package with the `[W]` mark and Walt, the Waggle bee.

This is a lean subset of the full kit: logo SVGs and key PNG marks, lockup SVGs, Walt mascot vectors and selected rasters, plus design tokens. Fonts, application mockups, and export archives are not included here; see the identity kit for the complete set.

`PROVENANCE.md` in this folder is copied from the kit and records mark geometry, mascot style lock, palette, and legal boundary.
