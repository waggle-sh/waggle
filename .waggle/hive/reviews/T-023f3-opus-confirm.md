## Notes (not blocking)

- N1: WAGGLE.md scopes the by-role rule to the summary file; the wider rule (cards, PR bodies, handoffs) is only in the summary's habits. After cutover, SessionStart prints `queen-<n>.md` and only points to the summary. Widening the WAGGLE.md clause to "and the queen refers to the Keeper by role, never by name, in every committed file, card, PR body and handoff" would keep the rule always loaded.
- N2: `probe/hold.sh` leaves `held.pl` on the tool shell's stdout and stderr. Claude Code 2.1.308 picks pipes or a file fd for tool output (`yEr` in the bundle). If it uses pipes and waits for them to close, `sh probe/hold.sh` blocks until `held.pl` exits at 120 s, or until the 120 s Bash tool timeout kills its group. Either way the run lands in the not-exercised case. Writing `perl probe/held.pl >/dev/null 2>&1 & sleep 1` costs nothing, keeps the 1 s listed shell (the difference from `bg.sh`), and removes that dependency. Raising `held.pl` to `sleep 300;` (still self-exiting, within rule 0's 300 s) also leaves room for a slow session.
- N3: `held.pl` is itself listed by the tracker, so it is caught by the pid path even if the group path failed. `result.json` does not say which path killed a survivor. The report item "which survivors came from the pid path and which from the group path" can only be inferred from the `ps-0a-during.txt` capture. Only an escaped `bg1` or `bg2` that still dies isolates the group path. Say so in the report rather than claiming `held` exercises the group path.
- N4: The installed Claude Code is 2.1.308, not the 2.1.304 of the D-176 probes. Step 1.3 already reports a difference; `ps-0a-during.txt` should confirm the tool shell still leads its own group before the gate is read.
- N5: In run 0c, if dispatch survives the close, the worker's `perl probe/probe.pl` hits the Bash tool's 120 s default timeout, the session ends normally, and `end` is `no_change` (exit 1), not `done`. Add `no_change` to the "kept running" list in 3.3.
- N6: Claude Code on macOS spawns a `caffeinate` sleep inhibitor in claude's own group. If one ever shows up in `survivors_killed`, the report should name it as Claude Code's, not a probe child.
- N7: The `e0beee4` commit message still says "she writes queen-1.md". It is history only; the committed text now says "next unused".
