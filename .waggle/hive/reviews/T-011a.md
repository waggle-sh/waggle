## Intent Packet
Phase A of T-011 changes what Waggle writes into a project and how it ranks file paths.
Waggle now owns one folder, .waggle/, split into control/ (the rules, Tier 3) and hive/ (task briefs, reviews, decisions).
Everything under .waggle/ except exact-case .waggle/hive/ is the highest-risk tier, including folders added later; CLAUDE.md and AGENTS.md at the repo root become Tier 2.
A worker lease that touches .waggle/ in any way, hive included, is now refused outright; nobody can configure around it.
waggle init edits CLAUDE.md or AGENTS.md and .gitignore only between markers, ignores only Waggle runtime files, never overwrites config.yaml, WAGGLE.md or local.yaml, refuses old layouts, and records the Waggle build in waggle.pin.
Generated templates, role prompts and the CI gate workflow change to the new paths; the gate now uses --no-renames.
Blast radius: every future hive receives these files; our own hive is unaffected until phase C moves it.
Open for the Head Keeper: uninstall cannot restore a project file that had no final newline exactly (phase B), and nested CLAUDE.md and .claude/ settings stay Tier 0.
