## Intent Summary

Adds the first waggled slice: a deterministic, stdlib-only `internal/decisions` package and a `waggle decide --file <path|-> [--repo] [--dry-run]` command that appends exactly one validated entry to `.waggle/hive/DECISIONS.md`. The file is a pure function of its entry list: a strict parser enforces `Render(Parse(x)) == x`, contiguous IDs, valid non-decreasing dates and backward-only supersedes, and `VerifyAppendOnly` rejects any change to existing bytes. Writes are serialized by an O_EXCL lock and replaced atomically via temp file, fsync and rename. Blast radius is limited to the new package, `cmd/waggle/decide.go`, a 4-line `main.go` edit and 87 backfill fixtures plus a golden. Nothing existing changes behavior. The command cannot verify that a Keeper approved a decision; that stays a process rule (doc comment and usage text).
