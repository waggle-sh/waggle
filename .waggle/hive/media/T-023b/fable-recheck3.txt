== Mechanism, reproduced on macOS
provision() runs "git worktree prune" before checkReusable. git's prune removes duplicate registrations that name the same
worktree path (prune_dups, keeps one). On Linux the test's AAA/gitdir and git's own T-023-builder/gitdir are byte-identical,
so prune deleted one of them and adminDir saw a single hit. On macOS the test writes /var/folders/... while git wrote
/private/var/folders/..., so prune saw no duplicate and the "%d registrations name" branch fired.
Patched scratch copy of the test to write filepath.EvalSymlinks(wt)+"/.git" into AAA/gitdir, run on macOS:
  --- FAIL: TestReuseRefusesExtraRegistration
      guard3_test.go:81: second registration for the path accepted: ... (lstat /private/var/.../.git/worktrees/AAA/commondir: no such file or directory)
Identical to the CI failure. Either way the reuse is refused with exit 3 before any git command runs against AAA.
