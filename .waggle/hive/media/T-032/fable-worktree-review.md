## Intent Summary
Adds `waggle claim` and `waggle release` as top-level verbs (`cmd/waggle/claim.go`) over two new library entry points, `dispatch.ClaimTask` (`task.go`) and `dispatch.ReleaseTask` (`release.go`), with a fixed version 1 JSON schema and an error-code map (`dispatch.ErrorCode`). `waggle dispatch release` becomes a thin wrapper that prints the same lines as before. Protected paths from `gate.protected_paths` now apply at lease time: `comb.Options.Protected` is checked in `prepareLease` for first claims, renewals and takeovers (error wraps both `ErrProtectedPath` and `ErrTier3Path`), dispatch reads the policy from the base revision only (`basePolicy` through `blobAt`, capped at `config.MaxFileSize`, fail closed on a symlink, tree, oversize or invalid file), refuses a covered `--dir` before any claim write, and the post-run check calls `CheckChangesPolicy` with it. `ResolveBase` resolves its default as `refs/remotes/<remote>/main` or `refs/heads/main`, and `offBranch` compares against the same qualified name, so a tag named `origin/main` or `main` no longer picks the base. Blast radius once the hive pin moves: every dispatch run reads base config and fails with exit 3 if that file is invalid at base; claim writes gain one refusal; the post-run verdict gains Tier 3 hits for listed paths; the dispatch default base can only change if someone pushes to main. This hive's config has no `gate:` section, so no verdict changes today.
