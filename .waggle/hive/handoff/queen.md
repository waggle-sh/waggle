## Habits that worked

- Brief first (scout), build in an isolated worktree (builder; scout for docs), review by the guard (opus by default; the second Tier 3 guard on fable) with explicit hostile probes in the prompt, Intent Packet in the merge commit, remove the worktree after merge (`git worktree remove --force`, then `git branch -D`).
- Open the draft PR yourself right after the build report so CI runs during review. Merge with `gh pr ready`, `gh pr update-branch` when main moved, require `product-ci` SUCCESS, then `gh pr merge --merge --admin --body-file` with the Intent Packet.
- Tier 2: merge on guard pass without a card when the Keeper has said to keep building. Tier 3 and anything touching policy, budgets, schema limits or spend: card, recommended option first, cost and reversibility stated. Batch rulings on one card.
- All open briefs use the new role names since T-020 phase C (D-142). Merged briefs, reviews and decisions keep the old names on purpose; tell builders that if they quote them.
- Builders blow line budgets by 1.5x to 3.3x (T-023 phase B hit 3.3x); D-136 sets the metric (added non-test lines). Expect it and let the guard rule.
- Never switch the main checkout's branch; use a scratchpad worktree. On macOS never check out a branch holding both `go.mod` and `GO.MOD` (use `git commit-tree`).
- `waggle decide` records only rulings the Keeper answered in the same session, so re-confirm carried rulings on a card.
- Guards in worktrees cannot write the main checkout: copy their review files and scan them for home paths and emails. Run guard rounds in parallel with the next fix when a must-fix is unambiguous. Guards must check linux CI, since macOS `/var` symlinks hide path bugs.
- Agents cannot be resumed after /clear; re-dispatch fresh.
- Keep Keeper messages short, lead with the answer, no em or en dashes anywhere.
- D-193: any test, probe or fix-removal check that calls the tracker's sweep(), or signals a process it did not spawn, runs only in the Colima linux container, never on the Keeper's Mac (a guard probe with root 0 killed every Keeper process twice on 2026-10-20). State it in every brief that touches dispatch process handling; prefer data tests over fabricated process tables.
- Colima is 2 CPU and 2 GB and also hosts the Keeper's Supabase stacks. Run one container at a time (`docker run --rm --init`, `GOGC=50 GOFLAGS=-p=1`), only the tests in question; leave full-package race runs to CI. Never stop Colima.
- The auto mode classifier blocks the queen's `gh pr merge --admin` and some force operations: hand the Keeper the exact command to run with `!`, or ask for an allow rule.
- A guard report that calls verify-leases-and-tiers a blocker is wrong until phase F (no claim refs; update-branch merge commits); merge through `--admin`.
- Hand off again before context passes about 200k. Rewrite `queen.local.md` after every merge; refresh this summary at phase merges and in records batches (D-182).
