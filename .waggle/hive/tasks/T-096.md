## 1. Goal

No example shows the gate working without a GitHub repo. A newcomer cannot see a pass and a fail locally.

## 2. Scope

- New `examples/gate-walkthrough/run.sh <path-to-waggle-binary>` works in a `mktemp -d` directory only: makes a bare repo as `origin` and a clone, runs `waggle init --gate-only`, commits it, writes `waggle claim T-001 --dirs src --gate light --branch t-001 --owner demo`, commits `T-001: add src/a.txt` on `t-001`, and runs `waggle gate verify --base main --head t-001` (exit 0 printed).
- It then adds a second commit `T-001: touch README.md` outside `src/` and shows `gate verify` exit 1 with the failing line.
- No network, no GitHub, no write outside the temp dir; the script removes it on exit. `set -eu`, POSIX sh.
- New `examples/gate-walkthrough/README.md` shows the real output of both runs, pasted from a run, and says what each line means.
- New `cmd/waggle/examples_test.go` builds the binary into a temp dir, runs `run.sh`, and asserts the two exit codes; it skips when `git` or `sh` is missing.
- The root README links the example in its Documentation list.

## 3. Checks

`go test -race ./cmd/waggle/...`, `sh -n examples/gate-walkthrough/run.sh`, vet, gofmt.
