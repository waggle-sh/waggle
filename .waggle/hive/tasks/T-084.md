## 1. Goal

`waggle hives status` reads each hive through `loadStatus(root, true)` (`cmd/waggle/hives.go:161`). Since T-081 that call returns `statusData.Collisions` from the same no-fetch scan as the claims, but `readHive` copies only the leases and the malformed count, so the collisions are dropped. Show them per hive, still with no fetch, in the words `waggle status` and `waggle doctor` already use.

## 2. Scope

- `HiveInput` gets the collisions from `readHive` (`d.Collisions`). `BuildHiveView` carries them into `HiveView`.
- Text output (`RenderHivesText`): after a hive's claimed list and its malformed line, one line per collision, indented like the malformed line: `    warning: <collisionPair>; <collisionImpact>. <collisionFix, first letter upper>.` This is the `waggle status` line (`renderStatus`), built from the shared constants in `cmd/waggle/collisions.go`, with no new wording. No line when there are none.
- JSON output: one additive field on each hive, `case_collisions`, always present (an empty list when there are none, like `claims`), each entry `{"ticket_a", "dir_a", "ticket_b", "dir_b"}`. `UnreachableView` sets it to an empty list. No existing field changes.
- Tests in `cmd/waggle`: one hive with two forged claims that differ only in case (reuse `forgeClaim` and `forgedCollisionLease` from `status_collision_test.go`) prints exactly one warning line and one `case_collisions` entry; one hive without prints no warning and `"case_collisions": []`; the run makes no fetch (an unreachable `forge.remote` still gives exit 0 and the hive is reachable); and the output passes `checkPlain` (no en or em dash).
- `docs/hives.md`: one bullet under the `hives status` list for the collision lines and the `case_collisions` field.

## 3. Out of scope

- `waggle doctor` (T-075) and `waggle status` output.
- `internal/comb`, the overlap rule and `DirsOverlap`.
- A count-only summary line, or collisions across hives (each hive's claims are its own).

## 4. Stop

The new tests pass, `go test ./...` and `go vet ./...` pass, the gate is green, docs-impact passes with `docs/hives.md`, and `site/content/cli.md` needs no change (its `hives status` row names only the flags). If the collisions cannot be read without a fetch or without `internal/comb`, stop and report instead of widening the lease.
