## 1. Goal

Scripts and agents read `--json`; nothing pins the shape.

## 2. Scope

- A new `cmd/waggle/json_golden_test.go` with files under `cmd/waggle/testdata/json/`: goldens for `claim --json`, `release --json`, `force-release --json` (inspect mode), `doctor --json` if it has one, `status --json` if it has one, and `nectar --json`, each from a fixed repo with fixed times (`--now`).
- Volatile values (object ids, timestamps) are replaced by placeholders before comparison.
- A `-update` flag rewrites the goldens; without it a difference fails with a diff.
- A "JSON output" paragraph in `site/content/cli.md` lists the top-level keys for each command that has `--json` and says new keys may be added but existing ones are not renamed in 0.x.
- Commands that have no `--json` are skipped, not changed.
