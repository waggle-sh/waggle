## 1. Goal

All git for new-kind claims: create, takeover, renew, release and list, each one atomic push with an expected old value.

## 2. Scope

- Create with an empty expected value; takeover after expiry plus grace as a child commit; `renew` of many refs in one atomic push, retried without any that moved; release deleting the ref and appending to `refs/waggle/claim-log` in one push.
- Listing with one `ls-remote` and an oid-keyed cache of claim commits.
- Acceptance: a 50-way create race on one key against a throwaway GitHub repo, exactly one winner, recorded for T-138.

## 3. Out of scope

- Writing hive `ticket-<n>` refs. The overlap decision itself (T-127, used by T-130).
