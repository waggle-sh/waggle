- **Status:** Approved by the Head Keeper on 2026-11-05. Built on branch `t-056-hive-approval`, PR #198, not merged. No guard review yet.

## 1. Goal

Today no claim can lease `.waggle/hive/` and no approval passes it, so every hive change needs an admin merge: 22 of the last 40 merged PRs did. Every adopter of `waggle init --gate-only` meets the same wall with `DECISIONS.md`.

A change under the exact-case `.waggle/hive/` passes `verify-leases-and-tiers` when the Head Keeper, the first entry of `gate.approvers` in the base config (D-233 approver rules), approved exactly the head commit.

## 2. Must stay

- Tier 3 control paths (`.waggle/` other than hive, `.github/workflows/`, CI files, Go dependency inputs) need an admin merge.
- Another approver's approval does not pass hive paths.
- `DECISIONS.md` accepts only pure appends of well-formed entries.
- A push after the approval invalidates it.

## 3. After merge

One Head Keeper admin merge: move the gate Action pin in `.github/workflows/waggle-gate.yml` and `waggle.pin` in `.waggle/control/config.yaml` to the merge commit, and add `gate.approvers` with the Head Keeper first. PR #198 names the lines.
