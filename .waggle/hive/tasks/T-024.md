## 1. Goal

RFC-0003 section 4 item 3 and amendment A2. Every worker (forager, builder, guard) runs in a Cell. A Cell has three targets:

1. **Zero credentials.** Nothing in the Cell's environment, home or readable files authenticates to git, a forge, SSH, a cloud, or a secret manager (D-061: "Cells hold zero credentials").
2. **`ro` repository, `rw` lease.** The worker reads its worktree and writes only the leased directories. `.git` is read-only.
3. **Egress lockdown.** The only route out is a per-Cell host egress proxy that admits allowlisted host names.

One interface, `CellRuntime`, with three backends: Seatbelt (macOS) and bubblewrap (Linux) as the default OS sandbox, and a Docker-compatible container backend for CI and stricter isolation. Each backend probes which targets it enforces on this host. A Cell never starts with a target unmet, and nothing ever runs unsandboxed as a fallback (D-067: state plainly what is not enforced, never degrade silently).

Out of scope: dispatch and worktree creation (T-023), the `run.sock` protocol (its own ticket), resource accounting, Windows.

## 3. Interface (phase A, `internal/cell/cell.go`)

```go
type Target string // "credentials" | "ro_repo" | "egress"

type Enforcement struct {
    Target   Target
    Enforced bool
    How      string // one line, e.g. "bind mounts in a mount namespace"
    Gap      string // empty when Enforced; else the plain reason
}

type Capabilities struct {
    Backend string        // "seatbelt" | "bwrap" | "container"
    Targets []Enforcement // always all three, in the order above
}

type Spec struct {
    TaskID   string   // canonical T-%03d
    Role     string   // claim role: forager | builder | guard
    Worktree string   // absolute host path of the Cell's worktree
    GitDir   string   // absolute host path of the common .git directory
    Leases   []string // repo-relative, from the claim; empty for forager and guard
    Socket   string   // absolute host path of run.sock
    Egress   string   // absolute host path of this Cell's proxy socket; empty means no route
    Home     string   // absolute host path of this Cell's empty home (created by waggled)
    Out      string   // absolute host path of this Cell's output dir (Q-T024-3)
    Argv     []string // from the AgentRuntime adapter
    Env      []string // adapter entries; merged through the allowlist
}

type CellRuntime interface {
    Name() string
    Probe(ctx context.Context) (Capabilities, error)
    Start(ctx context.Context, s Spec) (Cell, error) // refuses unless Probe reports all targets enforced
}

type Cell interface {
    Wait() (exitCode int, err error)
    Kill() error
}
```

Rules:
- `Start` calls `Probe` and refuses with `ErrNotEnforced` naming each unmet target and its `Gap`. There is no override flag (Q-T024-1 decides the one candidate exception).
- `Spec.Leases` are re-validated with the comb claim rules (import the comb validator; never a second copy) and must be the active claim's directories for `TaskID`.
- The fake backend lives in `internal/cell/celltest` so production code cannot select it. It runs `Argv` as a plain child process with the allowlisted env and reports every target `Enforced: false`; its `Start` ignores enforcement because only tests construct it.

### 3.1 Env allowlist (`env.go`)

The Cell env is built, never filtered. Allowed keys: `PATH` (fixed per backend, no host entries outside system and toolchain dirs), `HOME`, `TMPDIR`, `LANG`, `LC_ALL`, `TERM`, `WAGGLE_CELL=1`, `WAGGLE_SOCKET`, `HTTP_PROXY`, `HTTPS_PROXY`, `NO_PROXY` (empty), `GOFLAGS=-mod=readonly`, `GOPROXY=off`, `GOCACHE`, `GOMODCACHE`, `GIT_CONFIG_NOSYSTEM=1`, `GIT_CONFIG_GLOBAL=/dev/null`, `GIT_OPTIONAL_LOCKS=0`, `GIT_TERMINAL_PROMPT=0`, plus keys the adapter declares (today `BASH_MAX_OUTPUT_LENGTH`, `MAX_THINKING_TOKENS`, and the inference base URL of section 6.3). Anything else in `Spec.Env` is refused, not dropped, so an adapter bug shows up as an error. Never allowed under any spelling: `SSH_AUTH_SOCK`, `GIT_ASKPASS`, `SSH_ASKPASS`, and every key matching `*TOKEN*`, `*SECRET*`, `*PASSWORD*`, `*_KEY` (a second check behind the allowlist, so a future allowlist entry cannot reopen them).

### 3.2 Access plan (`plan.go`)

One pure function computes what every backend must enforce: `Plan(s Spec) (AccessPlan, error)`.
- `ReadOnly`: the worktree, `GitDir`, the toolchain roots (`go env GOROOT`, the agent CLI's install directory), the host module cache (`GOMODCACHE`), system dirs per OS.
- `ReadWrite`: each `Worktree/<lease>`, `Home`, `Out`, a per-Cell `GOCACHE` and `TMPDIR` under `Home`.
- `Sockets`: `Socket`, `Egress`.
- Leased directories that do not exist are created on the host before `Start` (git ignores empty directories). A lease entry that resolves, after `filepath.EvalSymlinks`, outside the worktree is refused.
- Nothing under the host user's home is readable except the paths above. `~/.ssh`, `~/.config`, `~/.gitconfig`, `~/.git-credentials`, `~/.aws`, `~/.claude*`, `~/Library/Keychains` and the main checkout outside the worktree are never in the plan.

### 3.3 `.git/config` credential scan

The Cell can read `GitDir/config`. Before `Start`, scan it: any remote or `url.*.insteadOf` URL with userinfo (`https://user:token@...`), any `http.*.extraHeader`, and any `credential.*` key refuses the Cell with a message naming the key, not the value. bubblewrap and the container backend could mask the file with a sanitized copy instead; Seatbelt cannot overlay a file. One rule for all backends: refuse.

## 4. Seatbelt backend (phase B)

Runs `/usr/bin/sandbox-exec -p <profile> -- <argv>`. The profile is generated from the access plan.

- **ro repository, rw lease:** `(deny default)`; `(allow file-read* (subpath ...))` for each `ReadOnly` and `ReadWrite` path and the system set; `(allow file-write* (subpath ...))` only for `ReadWrite`; `(deny file-link)` everywhere, because a hard link created inside the lease to a file outside it would be writable through the lease path. Paths are resolved with `EvalSymlinks` first (`/var` is `/private/var`).
- **Credentials:** env allowlist, empty `HOME`, no read rule for keychains or the host home; `(deny mach-lookup)` by default with an allowlist of the services basic tools need. Denied explicitly: `com.apple.SecurityServer`, `com.apple.securityd`, `com.apple.coreservices.launchservicesd`, `com.apple.dnssd.service`, AppleEvents. Without these denies a worker could reach the keychain, start apps outside the sandbox with `open`, or drive another app with `osascript`.
- **Egress:** `(deny network*)`; allow only `(remote unix-socket (path-literal <Egress>))` and `(path-literal <Socket>)`. The in-Cell forwarder (phase D) listens on loopback inside the process tree, and the profile allows `(local ip "localhost:<port>")` for that one port. DNS is closed by denying the mDNSResponder Mach service and socket.
- **Probe:** `sandbox-exec` present and runs a profile that denies a write; enforcement checks of section 9 pass in a throwaway Cell.

**Where Seatbelt falls short (say so in `How`/`Gap` and the README):**
- No mount namespace. The `ro`/`rw` split is a path rule over the real host paths, not a separate view. A path the plan forgets is reachable with the user's full permissions, which is why reads are allowlisted too.
- `sandbox-exec` and the profile language are deprecated and undocumented by Apple. They still work and other agent tools rely on them, but a macOS release could break or remove them. The probe catches that; the fallback is the container backend, chosen by config, never automatically to "no sandbox".
- Mach IPC is the largest residual surface. The allowlist is tuned by test, not by a spec.
- No resource limits (memory, process count) in v0.1 (Q-T024-10).
- Same user ID as the Keeper: the sandbox is the only barrier.

## 5. bubblewrap backend (phase C)

Runs `bwrap` with: `--unshare-all` (user, mount, PID, IPC, UTS, cgroup and network namespaces), `--die-with-parent`, `--new-session`, `--cap-drop ALL`, `--clearenv` then `--setenv` per allowlisted key, `--proc /proc`, `--dev /dev`, `--tmpfs /tmp`, `--ro-bind` for each system and `ReadOnly` path, `--ro-bind <Worktree> <Worktree>`, then `--bind` for each `ReadWrite` path (later binds override the `ro` bind), `--ro-bind` of the two sockets.

- **ro repository, rw lease:** real bind mounts. Hard links across mounts fail with `EXDEV`, so the Seatbelt hard-link gap does not exist here. Symlinks inside a lease that point outside resolve into `ro` mounts and stay read-only.
- **Credentials:** `--clearenv`, empty `HOME`, nothing from the host home is mounted.
- **Egress:** the network namespace has only loopback. The only way out is the bound proxy socket, reached through the forwarder. No DNS resolver exists.
- **Probe:** `bwrap` present, unprivileged user namespaces usable (run `bwrap --unshare-user true`), enforcement checks pass.

**Where bubblewrap falls short:**
- It needs unprivileged user namespaces. Ubuntu 24.04 restricts them by default through AppArmor, GitHub-hosted Ubuntu runners inherit that, some hardened kernels disable them, and inside an unprivileged Docker container they are blocked by the default seccomp profile. On those hosts the probe fails and the Keeper picks the container backend or changes the host setting; Waggle never changes it.
- No seccomp filter in v0.1, so the full syscall table is reachable (Q-T024-11).
- No resource limits in v0.1 (Q-T024-10).

## 6. Host egress proxy (phase D, `internal/cell/egress/`)

### 6.1 Proxy

One listener per Cell, on a Unix socket under the Cell's runtime dir; the socket identifies the Cell, so there are no proxy credentials. Standard library only.
- HTTP `CONNECT host:443` only, plus the plain-HTTP inference path of 6.3. No other methods, no other ports unless the allowlist entry names one.
- The allowlist is exact host names (`api.anthropic.com`), no wildcards in v0.1. Sources: the adapter's declared inference hosts, plus `cell.egress_allow` (Tier 3 config, section 7). With `egress_policy: strict` (today's default) only adapter hosts pass.
- Refused: IP literals, names that resolve to loopback, link-local (including `169.254.169.254`), RFC 1918 or ULA addresses, checked after resolution and pinned for the connection (no second lookup, so DNS rebinding cannot swap the address).
- No TLS interception. The proxy sees the `CONNECT` host, not the content.
- Every request is logged: Cell, host, port, bytes each way, allowed or refused.

### 6.2 In-Cell forwarder

Tools inside the Cell speak TCP to `HTTP_PROXY`. bubblewrap and the container backend have no route to the host, and Seatbelt only allows the socket path. The forwarder is the `waggle` binary itself (`waggle cell-forward --listen 127.0.0.1:<port> --socket <Egress>`), started as the Cell's first process, which then execs the agent. Tools that ignore proxy variables cannot connect at all, which fails closed.

### 6.3 Inference credential

Recommended default (Q-T024-1): the adapter points the agent at a plain-HTTP base URL on the forwarder (Claude Code: `ANTHROPIC_BASE_URL`); the proxy forwards to the real endpoint over TLS and adds the credential it holds on the host. The Cell never sees the key. Works for an API key or a token the Keeper provides to `waggled`. It does not cover a subscription login stored in the host keychain unless `waggled` reads that store, which it will not do by default. That case is Q-T024-1.

### 6.4 What egress lockdown does not stop

The inference endpoint is a channel out for anything the worker can read. Lockdown limits destinations, not content. The worker can read the whole worktree and `.git`, so anything in them can reach the inference provider. This is inherent to running an agent and is stated in the README.

## 7. Container backend (phase E, `internal/cell/container/`)

Calls the `docker` or `podman` CLI directly (Q-T024-9): `run --rm --read-only --network none --cap-drop ALL --security-opt no-new-privileges --user <uid>:<gid> --pids-limit 512 --memory <cfg> --tmpfs /tmp`, `-v <Worktree>:<Worktree>:ro`, `-v <lease>:<lease>:rw` per lease, the two sockets, `--env` per allowlisted key. Image and extra `runArgs` come from `.waggle/control/devcontainer.json` (D-030). `runArgs` that weaken isolation are refused: `--privileged`, `--network`/`--net` other than `none`, `--cap-add`, `--security-opt` with `unconfined`, `--pid host`, `--ipc host`, `--userns host`, `-v`/`--volume`/`--mount`, `--device`.

- **ro repository, rw lease:** bind mounts, as bubblewrap.
- **Credentials:** env allowlist; no host home mounted.
- **Egress:** `--network none` plus the proxy socket and forwarder.
- **Resource limits:** yes, the only backend with them in v0.1.
- **Probe:** CLI present, daemon reachable, image present locally (no pull from inside a Cell start), the agent CLI runs inside the image (`<binary> --version`), enforcement checks pass.

**Where the container backend falls short:**
- With rootful Docker, membership in the `docker` group is root on the host. That is a host property, not a Cell escape, but `waggle doctor` names it. Rootless Docker or podman avoids it.
- On macOS, Docker Desktop runs containers in a VM. Unix sockets bind-mounted from the host are not expected to work across that boundary, which would break both `run.sock` and the proxy socket. Unverified; phase E probes it and reports, and the default is Q-T024-5.
- The image must contain the agent CLI and the toolchain. The current `devcontainer.json` image (`mcr.microsoft.com/devcontainers/go:1.23`) has Go but not Claude Code.

## 8. Wiring (phase F)

- `internal/config`: `cell.backend: auto | seatbelt | bwrap | container` (default `auto`), `cell.egress_allow: []`, `cell.memory_mb` (container only). Existing keys stay: `egress_policy: strict` means adapter hosts only; `enforce_ro_root: false` is refused at load (Q-T024-12); `use_sparse_checkout` unchanged.
- `auto`: Seatbelt on macOS, bubblewrap on Linux; if that probe fails, the container backend when its probe passes; else refuse. The choice and the reason print on every Cell start. Never "no sandbox".
- `internal/runtime`: the adapter exposes its argv, env and inference hosts without starting a process, so `CellRuntime` launches it. The exact seam follows T-023's launch code; if T-023 already provides it, F only consumes it.
- `waggle doctor` gains a Cell section in T-018's report format: one line per target per backend, `enforced` or the `Gap` text.
- Commits: per Q-T024-2, `waggled` commits on the host after the lease diff check.

## 9. Tests

Phase A ships `internal/cell/celltest/conformance.go`: one suite every backend runs against itself. Each case starts a real Cell (skipped with a plain reason when the probe fails on this host, never silently passed):

1. Write inside a lease: succeeds. Write outside a lease, in the worktree: denied. Write to `.git/`, `.waggle/`, the main checkout: denied.
2. Create a new file in a leased directory that `waggled` pre-created: succeeds.
3. Hard link from inside a lease to a worktree file outside it, then write through it: the link or the write is denied.
4. Symlink inside a lease pointing outside, write through it: denied.
5. Read `~/.ssh`, `~/.gitconfig`, `~/.config`: fails. `env` output contains no key outside the allowlist.
6. Direct TCP to `1.1.1.1:443`: fails. DNS lookup of any name: fails.
7. Through the proxy: allowlisted host succeeds (phase D on); other host refused with 403; IP literal refused; a name resolving to `127.0.0.1` refused.
8. `git push` and `git fetch` from inside the Cell: fail.
9. Connect to `run.sock`: succeeds.
10. Seatbelt only: `open -a Terminal`, `osascript -e 'tell application "Finder" to ...'`, and a keychain query: fail.
11. Container only: a fork loop stops at the pids limit.

Unit tests (no sandbox): env allowlist refusals, access plan for leases with symlinks and missing dirs, `.git/config` scan cases, Seatbelt profile golden output, bwrap argv golden output, container argv and `runArgs` refusals, proxy allowlist and address checks against a fake resolver.

CI: product CI runs on `ubuntu-latest` only. Seatbelt conformance needs a macOS runner and bubblewrap conformance needs the AppArmor setting changed on the runner (Q-T024-7). Until then the builder runs the suite locally and saves output to `.waggle/hive/media/T-024<phase>/`.

## 10. Acceptance criteria (each phase, as it applies)

1. `go build ./...`, `go vet ./...`, `go test -race ./...` pass; gofmt clean.
2. The conformance suite passes for the phase's backend on a host where its probe passes, with output saved as evidence; skipped cases list their reason.
3. `Probe` reports every target with `How` or `Gap`; `Start` refuses when any target is unmet (test with a stub probe).
4. No credential value appears in any log, error or evidence file (grep the evidence for the test token).
5. No backend, config value or flag runs a worker without a sandbox.
6. Physical non-test line count against the section 2 target and stop.
7. No U+2013 or U+2014 in code, docs or output.

## 12. Questions for the Keeper (ruled 2026-10-17)

- **Q-T024-1 (credentials): Inference credential.** Default: the egress proxy injects it (section 6.3) and the Cell holds none. A subscription login the proxy cannot inject is not supported in Cells in v0.1; `waggle doctor` says so. Alternative: an opt-in `cell.inference_credential: passthrough` that places the agent's own login token in the Cell and reports the credentials target as not enforced. Kind `credentials`: never auto-applied. **Ruling (D-120):** the default plus the alternative as an opt-in. The product default is proxy injection with zero credentials in the Cell. `cell.inference_credential: passthrough` is built as an opt-in, and our hive opts into it; `waggle doctor` reports the credentials target as not enforced. Decided by the Head Keeper via queen card on 2026-10-17.
- **Q-T024-2 (policy): Who commits.** Default: Cells never write `.git`; `waggled` commits on the host after checking the diff against the lease, with the `T-<id>:` subject. Alternative: give the Cell write access to `.git`, which lets a worker write any ref, including `refs/heads/main` and `refs/waggle/claims/*`, from inside the sandbox. **Ruling (D-121):** default. `.git` read-only; `waggled` commits on the host. Decided by the Head Keeper via queen card on 2026-10-17.
- **Q-T024-3 (technical): Forager and guard output.** They lease nothing, and review and media files are hive paths no worker may write (RFC 3.1). Default: each Cell gets an `Out` directory outside the repo; `waggled` validates and copies it into `.waggle/hive/reviews/` and `.waggle/hive/media/`. Alternative: send files over `run.sock`. **Ruling (D-122):** default. The `Out` dir, copied by `waggled`. Queen default, within authority; approved on the Head Keeper's queen card on 2026-10-17.
- **Q-T024-4 (strategy): Start before the `run.sock` loop.** D-014 puts Cells after dispatch and the `run.sock` loop. Default: phases A to E dispatch after T-023 merges (they are libraries with no caller), and phase F waits for the `run.sock` loop. Alternative: hold every phase until the loop merges. **Ruling (D-123):** default. Phases A to E after T-023 merges, F after the `run.sock` loop. Decided by the Head Keeper via queen card on 2026-10-17.
- **Q-T024-5 (scope): Container backend on macOS.** Default: supported on Linux hosts and CI only in v0.1; on macOS the probe reports it unsupported unless the socket check of section 7 passes. Alternative: add a TCP transport for `run.sock` and the proxy, which needs a per-Cell secret and so weakens the zero-credentials target. **Ruling (D-124):** default. Linux hosts and CI only; macOS only if the socket check passes. Decided by the Head Keeper via queen card on 2026-10-17.
- **Q-T024-6 (technical): Registry egress.** Default: `strict` keeps registries closed; Go builds use `GOPROXY=off` with the host module cache mounted read-only, and a missing module fails the build. Hosts for other ecosystems are added by exact name in `cell.egress_allow` (Tier 3 config). Alternative: allow `proxy.golang.org` and `sum.golang.org` by default. **Ruling (D-122):** default. Registries closed, `GOPROXY=off` with a read-only module cache. Queen default, within authority; approved on the Head Keeper's queen card on 2026-10-17.
- **Q-T024-7 (spend): Sandbox tests in CI.** Default: add two jobs to `ci.yml`, path-filtered to `internal/cell/**`: one on `macos-latest` for Seatbelt, one on `ubuntu-latest` that sets `kernel.apparmor_restrict_unprivileged_userns=0` for bubblewrap. macOS minutes bill at 10 times Linux on private repos; at about 4 minutes per run that is about 40 included minutes per macOS run out of GitHub Team's 3,000 per month. `ci.yml` is Tier 3: a Head Keeper commit. Alternative: local evidence only. **Ruling (D-125):** default. Two path-filtered jobs, Head Keeper commit. Decided by the Head Keeper via queen card on 2026-10-17.
- **Q-T024-8 (policy): CODEOWNERS for `internal/cell/`.** Default: add `/internal/cell/ @paulternate` (Head Keeper commit, as T-015), not a hardcoded Tier 3 entry, because a hardcoded path would apply to every host repo's own `internal/cell/` (the D-043 reasoning used for `docs/GLOSSARY.md`). Alternative: rely on guard Tier classification alone. **Ruling (D-126):** default. Decided by the Head Keeper via queen card on 2026-10-17.
- **Q-T024-9 (technical): devcontainer CLI.** Default: call `docker` or `podman` directly and read only `image` and `runArgs` from `devcontainer.json`, so no Node dependency. Alternative: require `devcontainer up`, which supports the full spec (features, lifecycle hooks) and runs hook commands Waggle cannot vet. **Ruling (D-122):** default. `docker` or `podman` directly.
