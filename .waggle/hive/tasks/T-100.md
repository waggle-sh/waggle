## 1. Goal

CI runs build, vet, gofmt and race tests on Linux only. Releases ship macOS and Windows archives that nothing cross-compiles before the tag. Changing the workflow is Tier 3, so this ticket gives contributors and the Head Keeper a script that does it.

## 2. Scope

- New `scripts/check.sh` runs, in order: `go build ./...`, `go vet ./...`, the gofmt check over tracked files exactly as `ci.yml` does it, and `go test -race ./...`; each step prints a header and the script stops at the first failure with that step's name.
- `scripts/check.sh --cross` additionally runs `GOOS=<os> GOARCH=<arch> go build -o /dev/null ./cmd/waggle` for linux, darwin and windows on amd64 and arm64, and `go vet` for darwin and windows. The matrix is read from `.github/workflows/release.yml` if it lists one, otherwise hard-coded with a comment saying why.
- `--quick` skips the race tests.
- POSIX sh, `set -eu`, passes `sh -n`; runs from any directory by finding the repo root.
- The `CONTRIBUTING.md` Build and test bullet names the script and the flags.
- Any cross-build failure it finds is reported in the PR body with the file and error; fix only if it is a missing build tag or a one-file portability fix.

## 3. Checks

`sh -n scripts/check.sh`, `scripts/check.sh --quick --cross`, `gofmt -l .`.
