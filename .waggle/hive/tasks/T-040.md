## 5. Threat model (D-203)

**Attackers.** The PR author (agent or person), who controls commits, subjects, trailers, branch names and paths; this ticket changes what the gate prints about them, not what it decides. A CLI user of `claim`, `release`, `upgrade`, `uninstall` and `decide` is trusted with their own repo.

**Trusted.** The base revision and its config, the pinned build, the Head Keeper.

**Harm this ticket can do.** A reworded message that hides a failure, loses the path, commit or cause it names, tells the reader no bypass is needed where one is, or suggests a step that weakens protection (for example, leasing `.waggle/` or `.github/`, or that approval passes a hardcoded path). A template edit that changes anything a workflow runs. A gate-only decision input that `waggle decide` refuses.

**Must-fix:** any changed exit code, JSON error code, gate result, finding rule, finding path, or the check a finding prints under; any sentinel whose `errors.Is` identity changes; any change to the `Head Keeper: ` prefix test, binding, claims, approver logic or the decisions parser; a reworded string that drops a fact the old one carried other than a bee name or a reference to this repo's records (the commit OID, the subject, the path, the branch, the `%w` cause, the need for an admin bypass or merge, the `--unmerged` and `--allow-downgrade` instructions); row 1 matching the listed-path text; a template diff other than the one step name and two comment lines, or one that changes a YAML value, a job id, a trigger, a permission or a `run:` line; a gate-only decision input that names a ticket or decision ID or that `decisions.Next` refuses; a full-hive decision input that differs from today; a bee name added anywhere in program output; a file outside the lease rule; any em or en dash added.

**Note, not must-fix:** wording within a "within" row; comment wording; line wrap of the gate usage paragraph; a string the build finds reachable and lists without changing.

**Guard prompt sentence (repeat verbatim):** "Threat bar (D-203): this ticket changes text only; must-fix is any changed exit code, JSON code, sentinel identity, gate result, finding rule or path, any reworded message that drops a fact other than a bee name or a reference to this repo's records, any message that understates a needed admin bypass or suggests weakening protection, any template change beyond the one step name and two comments, a gate-only decision input that names a ticket or decision or fails decisions.Next, a full-hive decision input that changed, and files outside the lease rule; wording choices are notes."
