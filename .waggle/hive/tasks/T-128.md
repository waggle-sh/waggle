## 1. Goal

Render each claim onto its GitHub issue from the CLI at claim time, best effort, never failing the claim.

## 2. Scope

- Issue tasks: assignee when assignable, the `claimed` label, one sticky comment found by its marker and edited in place, full state each time.
- Backlog.md tasks: a window issue on first claim, body rendered from the file at the default branch head under the overwrite banner, reused later, closed when the task finishes; an issue named in the task's `references` is used instead and its body left alone.
- Release, back-off and takeover renders; the assignee removed only if Waggle set it.
- Planned cut: window issues with title, link and banner only.

## 3. Out of scope

- Reading anything back from an issue. Linear (T-129).
