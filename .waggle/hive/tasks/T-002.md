# T-002: Git-ref CombBackend (RFC-0003 v0.1 Commit #2)

- **Status:** Ready for Forager
- **Gate:** `full`
- **Risk Tier:** Tier 2 (shared module, concurrency semantics, well over 150 lines)
- **Role:** `forager` (implementation), `guard` (Full-gate review)
- **Lease (rw):** `internal/comb/` (all files, including `internal/comb/testdata/`)
- **Read-only context:** `WAGGLE.md`, this brief, `go.mod`
- **Depends on:** T-001 (bootstrap; `internal/comb/backend.go` exists)
- **Commit subject prefix:** `T-002:`

## 1. Goal

Implement the single Comb codepath from RFC-0003 section 3.1: per-ticket claim refs at `refs/waggle/claims/ticket-<id>`, written with atomic Compare-And-Swap (CAS) on a local `.git` (Scale = 1) and on a remote such as `origin` (Scale = 500+), plus a pure renderer for the derived `WORKPLAN.md` view.

Go 1.23, module `github.com/waggle-dev/waggle`, **standard library only**. Do not add dependencies or touch `go.mod` / `go.sum`.

## 2. Background (what you need from RFC-0003, nothing more)

- Claims live in Git refs, one ref per ticket. `WORKPLAN.md` is a derived view, never a competing state store.
- Ref writes give atomic CAS **per ticket**, not per directory. Two Keepers claiming different tickets with overlapping directories can both pass the claim-time check. **Invariant:** directory leases are optimistic at claim time and authoritative at merge time (`waggle-gate.yml`). Document this in the `GitBackend` and `AcquireLease` doc comments. Do not try to close the TOCTOU window.
- Comb modes: `direct` (push refs) and `relay` (Forge Action Relay). Only `direct` is in scope here.
- Tier 3 paths (`HardcodedTier3Prefixes` in `backend.go`) are Controller-only and must never be leased to a worker.

## 4. Keeper Decisions (approved, mandatory)

### 4.1 Commit wrapping
- `refs/waggle/claims/ticket-<n>` points to a **commit**. That commit's tree contains exactly one entry: `lease.json` (mode `100644`, the JSON-encoded `Lease`).
- A first claim is a root commit (no parent).
- A **renewal** (same `KeeperID` re-acquiring its own claim) and a **takeover** (any Keeper acquiring an expired claim) create a **child commit whose single parent is the previous claim commit**. This gives an audit chain readable with `git log <ref>`.
- **Release deletes the ref.**
- RFC-0003 section 3.1 says "JSON blobs". That wording needs an amendment to "commits whose tree holds `lease.json`". The amendment is a separate docs change owned by the architect and is **not** part of this lease. Do not edit `docs/`.

### 4.2 Tier 3 rejection
`AcquireLease` must refuse any lease where **any** directory:
1. equals a Tier 3 path, or
2. is contained by a Tier 3 path (`RequiredMinTier(dir) == Tier3ControlAuth`), or
3. **contains** a Tier 3 path (for example `.github` contains `.github/workflows/`; the repo root contains `WAGGLE.md` and `.gitlab-ci.yml`).

`""`, `"."`, `"/"`, `"./"` and anything that cleans to the repo root contain everything and must be rejected. Return `ErrTier3Path` (wrapped with the offending directory in the message; `errors.Is(err, ErrTier3Path)` must hold). Compare Tier 3 membership **case-insensitively** (macOS and Windows checkouts are case-insensitive, so `.WAGGLE/` or `waggle.md` must also be rejected). Do not change `RequiredMinTier` itself.

## 5. Public API

Names below are requirements unless marked "suggested". Doc comments on every exported identifier.

### 5.1 Sentinel errors (in `backend.go`)

```go
var (
    ErrInvalidTicketID     = errors.New("comb: invalid ticket id")
    ErrInvalidLease        = errors.New("comb: invalid lease")
    ErrTier3Path           = errors.New("comb: lease covers a Tier 3 control-plane path")
    ErrGateTooLow          = errors.New("comb: light gate cannot lease a Tier 2 steering path")
    ErrLeaseOverlap        = errors.New("comb: directories overlap an active lease")
    ErrAlreadyClaimed      = errors.New("comb: ticket already claimed")
    ErrNotFound            = errors.New("comb: claim not found")
    ErrNotOwner            = errors.New("comb: claim owned by another keeper")
    ErrConcurrentUpdate    = errors.New("comb: claim changed during release")
    ErrMalformedClaim      = errors.New("comb: malformed claim ref")
    ErrRelayNotImplemented = errors.New("comb: relay comb mode not implemented in v0.1")
)
```

All returned errors that correspond to these conditions must satisfy `errors.Is`. Wrap with `fmt.Errorf("...: %w", ErrX)` to add context. Never return a bare git stderr string for a condition that has a sentinel.

### 5.2 Ticket IDs

```go
// ParseTicketID accepts "T-<digits>" or "<digits>" and returns the canonical ID.
func ParseTicketID(s string) (canonical string, err error)
// RefName returns refs/waggle/claims/ticket-<n> for a valid ticket ID.
func RefName(ticketID string) (string, error)
```

- Accepted input pattern: `^(T-)?[0-9]{1,6}$`. Uppercase `T-` only. Value must be `>= 1`.
- Reject everything else with `ErrInvalidTicketID`: empty, whitespace, `t-1`, `T-`, `T-0`, `-1`, `1a`, `1/2`, `../x`, `1..2`, `ticket-1`, `T-1234567`, NUL, newline, `@{`, unicode digits. This blocks ref-name injection.
- **Canonical display form:** `T-%03d` (so `1`, `001`, `T-1`, `T-001` all become `T-001`; `T-1234` stays `T-1234`). This matches `docs/tasks/T-<id>.md` file names.
- **Canonical ref form:** `refs/waggle/claims/ticket-<n>` with the decimal integer and **no zero padding** (`T-001` maps to `ticket-1`). Leading zeros therefore can never create two refs for one ticket.
- `Lease.TicketID` is always stored in canonical display form.
- When reading refs, a ref under `refs/waggle/claims/` whose suffix is not `ticket-<n>` (canonical, no leading zeros) is reported as malformed (section 7.4), not parsed.

### 5.3 Directory validation

```go
// NormalizeDirectories validates and canonicalizes a lease's directory list.
func NormalizeDirectories(dirs []string, maxDirs int) ([]string, error)
```

For each entry, in order:
1. Reject empty or whitespace-only strings, strings containing NUL, `\`, or glob metacharacters `* ? [` (v0.1 leases are literal directories, not globs).
2. Reject absolute paths: leading `/`, or `filepath.IsAbs`, or a Windows volume prefix (`filepath.VolumeName != ""`).
3. `cleaned := filepath.ToSlash(filepath.Clean(d))`, then trim a trailing `/`.
4. Reject `.` (repo root) and anything equal to `..` or starting with `../` (escapes repo).
5. Reject any path whose first segment is `.git` (case-insensitive). Leasing the git dir gives a Cell write access to hooks.

Then: reject an empty list, reject `len > maxDirs` (after dedupe), dedupe exact duplicates, and sort ascending. Failures return `ErrInvalidLease`, except entries that clean to the repo root, which return `ErrTier3Path` (the root contains Tier 3 files).

Expected sentinels for root-like input: `""` returns `ErrInvalidLease` (empty entry); `"."`, `"./"`, `"a/.."` return `ErrTier3Path`; `"/"` returns `ErrInvalidLease` (absolute). Either way nothing root-like is ever accepted.

### 5.4 Overlap

```go
// DirsOverlap reports whether two normalized directories overlap on a path-segment boundary.
func DirsOverlap(a, b string) bool
```

True iff `a == b`, or `strings.HasPrefix(b, a+"/")`, or `strings.HasPrefix(a, b+"/")`. `internal/comb` and `internal/combx` do **not** overlap. `internal` and `internal/comb` do.

### 5.5 GitBackend

```go

    RepoDir                string           // required; absolute or relative path to a git work tree or bare repo
    Remote                 string           // "" = local-only; otherwise remote name, e.g. "origin"
    CombMode               string           // "direct" (default when "") | "relay"
    MaxDirectoriesPerClaim int              // <= 0 means default 5 (leases.max_directories_per_claim)
    DefaultTTL             time.Duration    // <= 0 means default 120m (leases.default_ttl_minutes)
    Now                    func() time.Time // nil means time.Now
    GitBinary              string           // "" means "git"
    ExtraEnv               []string         // appended to the git child env (tests use this)
}

func NewGitBackend(opts Options) (*GitBackend, error)
var _ Backend = (*GitBackend)(nil)
```

- `NewGitBackend` validates: `RepoDir` non-empty; `CombMode` is `direct`, `relay`, or `""`; `Remote` (if set) matches `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$` (no leading `-`, so it can never be parsed as a git flag). It does not need to run git.
- In `relay` mode every `Backend` method returns `ErrRelayNotImplemented`.
- The `Backend` interface keeps its three methods and signatures. You may add doc text. Additional exported methods on `GitBackend` are allowed if they help tests (suggested: `ClaimOID(ctx, ticketID) (string, error)`), but keep the surface small.
- Wiring config from `.waggle/config.yaml` into `Options` is **out of scope** (no YAML parser; CLI wiring comes later).

## 6. Git Execution Rules

- Every git call goes through one helper using `exec.CommandContext(ctx, gitBinary, "-C", repoDir, args...)`. Arguments are separate argv entries. **No shell**, no `sh -c`, no string concatenation of commands.
- Child env: `os.Environ()` plus `GIT_TERMINAL_PROMPT=0`, `LC_ALL=C` (stable messages for parsing), plus `Options.ExtraEnv`.
- Capture stdout and stderr separately; on failure wrap an error that includes the git subcommand and trimmed stderr.
- Never touch the working tree or the index. Allowed plumbing: `hash-object`, `mktree`, `commit-tree`, `update-ref`, `for-each-ref`, `cat-file`, `rev-parse`, `fetch`, `push`. Do not use `checkout`, `add`, `commit`, `reset`, `stash`, or `notes`.
- Validate every OID read from git against `^[0-9a-f]{40}([0-9a-f]{24})?$` before use.
- Zero OID for create-only CAS: all zeros at the repo's hash length. Detect length via `git rev-parse --show-object-format` (`sha1` = 40, `sha256` = 64), cached per backend.

### 6.1 Building a claim commit
1. JSON-encode the lease with `json.MarshalIndent(lease, "", "  ")` plus a trailing `\n`. Times are normalized to UTC and truncated to whole seconds before encoding.
2. `git hash-object -w --stdin` with the JSON on stdin returns the blob OID.
3. `git mktree` with stdin `100644 blob <blob>\tlease.json\n` returns the tree OID.
4. `git commit-tree --no-gpg-sign <tree> [-p <parent>] -m <message>` returns the commit OID. Message (suggested): `waggle: claim T-001 by <keeper_id> (<role>, <gate>)`; use `renew` or `takeover` instead of `claim` when there is a parent.
5. Set deterministic identity env for `commit-tree` so it works with no git user config: `GIT_AUTHOR_NAME=waggle`, `GIT_AUTHOR_EMAIL=waggle@localhost`, same for `GIT_COMMITTER_*`, and `GIT_AUTHOR_DATE` / `GIT_COMMITTER_DATE` = `@<unix> +0000` from the injected clock.

## 7. Behavior

### 7.1 Local-only mode (`Remote == ""`)

**AcquireLease(ctx, lease)**
1. Validate (section 7.3). Fill defaults: `Version` 0 becomes 1 (any other non-1 version is `ErrInvalidLease`); zero `ClaimedAt` becomes `now`; zero `ExpiresAt` becomes `ClaimedAt + DefaultTTL`. Reject `ExpiresAt <= now`.
2. Read the current ref OID for the ticket (absent = zero OID).
3. If present, read and decode its `lease.json`:
   - Malformed: return `ErrMalformedClaim`.
   - Active and `KeeperID` differs: `ErrAlreadyClaimed`.
   - Active and same `KeeperID`: renewal (parent = current OID).
   - Expired: takeover by any Keeper (parent = current OID).
4. Overlap check against all **other** active leases from the same scan (section 7.4). Any overlap returns `ErrLeaseOverlap` naming the other ticket and both directories.
5. Build the commit (6.1), then `git update-ref -m <msg> <ref> <new> <expected>` where `<expected>` is the exact OID read in step 2 (zero OID for create-only).
6. If `update-ref` fails, re-read the ref. If it no longer equals `<expected>`, return `ErrAlreadyClaimed` (race lost). If it still equals `<expected>` and stderr shows lock contention (`cannot lock ref`, `Unable to create '...lock'`), retry `update-ref` up to 5 times with a short backoff (10 to 50 ms), then return the wrapped git error. Without this retry the loser can re-read before the winner's write lands and surface a generic error, which makes test 12 flaky.

**ReleaseLease(ctx, ticketID, keeperID)**
1. Parse the ticket ID. Read the ref OID. Absent: `ErrNotFound`.
2. Decode the lease. Malformed: `ErrMalformedClaim`. `KeeperID != keeperID`: `ErrNotOwner` (applies to expired claims too; a non-owner takes over with `AcquireLease` instead).
3. `git update-ref -d <ref> <oid>` with the OID read in step 1. On failure, re-read: if the ref changed or vanished, return `ErrConcurrentUpdate`; otherwise the wrapped error.

**ListActiveLeases(ctx)**
- `git for-each-ref --format=%(refname)%00%(objectname) refs/waggle/claims/` (or an equivalent unambiguous format), read each `lease.json` via `git cat-file blob <commit>:lease.json`, keep leases with `ExpiresAt > now`.
- Return leases sorted by numeric ticket ID.

### 7.2 Remote mode (`Remote != ""`, `CombMode == "direct"`)

In remote mode the remote is authoritative and local `refs/waggle/claims/*` is a mirror. Never write a local claim ref except to mirror a successful push.

- **Sync** before every read or write: `git fetch --prune --no-tags --quiet <remote> +refs/waggle/claims/*:refs/waggle/claims/*`. An empty remote namespace is not an error.
- **AcquireLease:** sync, then steps 1 to 4 and 6.1 exactly as local mode, then: `git push --atomic --porcelain <remote> --force-with-lease=<ref>:<expected> <new>:<ref>` where `<expected>` is the OID read after sync, or **empty** (`--force-with-lease=<ref>:`) for create-only (ref must not exist). On success, mirror locally with `git update-ref <ref> <new>`.
- **Race classification:** if the push exits non-zero, parse `--porcelain` output. A `!` (rejected) status line for the claim ref, including `stale info`, `fetch first`, `already exists`, or `non-fast-forward`, returns `ErrAlreadyClaimed`. Before returning `ErrAlreadyClaimed`, re-sync once: if the remote ref still equals `<expected>` (both pushers lost on receive-pack lock contention, so nobody won), retry the push up to 5 times with a short backoff; otherwise return `ErrAlreadyClaimed`. Transport and auth failures (no porcelain status line for the ref) return the wrapped git error. Losing a race must **never** surface as a generic error, and a race must never end with zero winners when retries remain.
- **ReleaseLease:** sync, then steps 1 and 2 as local, then `git push --atomic --porcelain <remote> --force-with-lease=<ref>:<oid> :<ref>`. Rejection returns `ErrConcurrentUpdate`. On success, `git update-ref -d <ref> <oid>` locally (ignore a mirror mismatch; the next sync fixes it).
- **ListActiveLeases:** sync, then read as local.

### 7.3 Lease validation (both modes, before any git write)
- Ticket ID parses (5.2); store canonical form.
- `KeeperID` matches `^[A-Za-z0-9][A-Za-z0-9._@+-]{0,127}$`.
- `Role` in {`scout`, `forager`, `guard`}; `Gate` in {`light`, `full`}.
- Directories pass `NormalizeDirectories` (store the normalized list).
- **Tier 3 rejection** per 4.2: `ErrTier3Path`.
- **Tier 2 floor:** if any directory equals, contains, or is contained by a `HardcodedTier2MinPrefixes` path and `Gate == "light"`, return `ErrGateTooLow`. (The architect role may never downgrade Tier 2 work to a Light gate.)
- `ClaimedAt` must not be after `ExpiresAt`.

### 7.4 Malformed claims
A claim ref is malformed if its name is not canonical `ticket-<n>`, it does not point to a commit, the tree lacks `lease.json`, the JSON does not decode, the decoded `TicketID` does not match the ref, or decoded directories fail `NormalizeDirectories`.

- `ListActiveLeases` never panics. It returns all valid active leases **and** a non-nil error of type `*MalformedClaimsError` (wraps `ErrMalformedClaim`, lists each ref name and reason) when one or more refs are malformed. Callers use `errors.As`. Document that the returned slice is valid in this case. Git or transport failure returns `nil, err`.
- `AcquireLease` ignores malformed refs for **other** tickets during the overlap check (overlap is optimistic anyway; the merge gate is authoritative) but refuses a malformed ref for the **target** ticket with `ErrMalformedClaim`.

```go
type MalformedClaimsError struct{ Claims []MalformedClaim }
type MalformedClaim struct{ Ref, Reason string }
func (e *MalformedClaimsError) Error() string
func (e *MalformedClaimsError) Unwrap() error // returns ErrMalformedClaim
```

### 7.5 Context and clock
All methods honor `ctx` (pass it to every `exec.CommandContext`). Every expiry decision uses `Options.Now`, never `time.Now` directly.

## 8. WORKPLAN.md Renderer (`workplan.go`)

```go
func RenderWorkplan(leases []Lease, now time.Time) []byte
func WriteWorkplan(path string, leases []Lease, now time.Time) error
```

- **Pure:** no git, no filesystem, no clock reads, no map iteration in output order. Same input yields byte-identical output.
- `now` is used **only** to drop leases with `ExpiresAt <= now`. It must not appear in the output (a timestamp would churn the file on every render).
- Sort a copy of the input (do not mutate the caller's slice) with `sort.SliceStable` by numeric ticket ID. Unparseable ticket IDs sort last, by raw string.
- Exact layout (LF line endings, single trailing newline):

```
<!-- GENERATED FILE: derived from refs/waggle/claims/* by waggled. Do not edit by hand. -->
# WORKPLAN

> Derived view of active Comb claims. Edits here are overwritten and never change a claim.

| Ticket | Keeper | Role | Gate | Directories | Claimed (UTC) | Expires (UTC) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| T-002 | paulternate | forager | full | `internal/comb` | 2026-10-17T14:00:00Z | 2026-10-17T16:00:00Z |
```

- Directories render as backtick-wrapped entries joined by `, `. Times are UTC RFC 3339 at second precision. Escape `|` as `\|` and replace newlines with spaces in every cell (renderer input is not trusted to be validated).
- With zero active leases, replace the table with the single line `_No active claims._`.
- `WriteWorkplan`: render, `os.CreateTemp(filepath.Dir(path), ".WORKPLAN-*.tmp")`, write, `Sync`, `Close`, `Chmod 0o644`, `os.Rename` onto `path`. Remove the temp file on any error. Never write a partial file at `path`.
- Do not write the repo's own `WORKPLAN.md` in this task (it is a Tier 2 path and outside the lease). Tests write only under `t.TempDir()`.

## 9. Tests

Run with `go test -race ./...`. All test repos live under `t.TempDir()`.

### 9.1 Harness rules
- A helper calls `exec.LookPath("git")` and `t.Skip("git not found")` when absent. Every git-backed test uses it. Pure tests (ticket IDs, directories, overlap, renderer) never skip.
- Isolate from the developer's git config through `Options.ExtraEnv` and the helper's own setup commands: `GIT_CONFIG_GLOBAL=/dev/null`, `GIT_CONFIG_NOSYSTEM=1`. Do not use `t.Setenv` in parallel tests.
- Setup uses `git init -q` (local), `git init -q --bare` (origin), and two clones (or two `init` plus `remote add origin`). No initial commit is required.
- Use an injected fake clock (`func() time.Time` over a mutex-guarded value) for expiry.

### 9.2 Required test cases
1. **Ticket IDs (table):** valid inputs and canonical forms (`1`, `001`, `T-1`, `T-001`, `T-1234`, `999999`), ref mapping (`T-001` to `refs/waggle/claims/ticket-1`), and every invalid input listed in 5.2 returns `ErrInvalidTicketID`.
2. **Directories (table):** normalization (`internal/comb/` to `internal/comb`, `./internal//comb` to `internal/comb`, dedupe, sort), rejections with the exact sentinel: empty list, `""`, `"/"`, `"/etc"`, `"../x"`, `"a/../../x"`, `"."`, `"./"`, `"a/.."`, `".git"`, `".git/hooks"`, `"internal/*"`, `"a\\b"`, more than `maxDirs` entries.
3. **Tier 3 rejection:** each of `.waggle`, `.waggle/roles`, `WAGGLE.md`, `.devcontainer`, `.github`, `.github/workflows`, `.github/workflows/x`, `.gitlab-ci.yml`, `.WAGGLE`, `waggle.md`, `.` returns `ErrTier3Path` from `AcquireLease`, and **no ref is created**. `.github/ISSUE_TEMPLATE` is allowed.
4. **Tier 2 floor:** `docs/specs` with gate `light` returns `ErrGateTooLow`; with `full` succeeds. `docs` with `light` is also refused (contains `docs/specs/`).
5. **Overlap:** `DirsOverlap` table including `internal/comb` vs `internal/combx` (false), `internal` vs `internal/comb` (true), equal paths (true). Backend-level: active `T-001` on `internal/comb` blocks `T-002` on `internal` with `ErrLeaseOverlap`; allows `T-003` on `internal/combx`; an **expired** lease on `internal/comb` does not block.
6. **Local acquire and commit shape:** after `AcquireLease`, the ref points to a commit with no parent whose tree has exactly one entry `lease.json`, and `cat-file` of it decodes to the stored lease. `git status --porcelain` output and `.git/index` existence are unchanged (working tree and index untouched). Works with no `user.name` configured.
7. **Already claimed:** a second Keeper acquiring an active ticket gets `ErrAlreadyClaimed`.
8. **Renewal:** same Keeper re-acquires; new commit's parent equals the old OID.
9. **Expiry takeover:** advance the fake clock past `ExpiresAt`; another Keeper acquires; new commit's single parent equals the previous claim OID; `git log` on the ref shows 2 commits.
10. **Release:** owner release deletes the ref; second release returns `ErrNotFound`; non-owner release returns `ErrNotOwner` and the ref still exists; releasing an invalid ticket ID returns `ErrInvalidTicketID`.
11. **Malformed:** create refs by hand with plumbing in the test (a blob instead of a commit; a commit whose `lease.json` is `{not json`; a commit without `lease.json`; a ref named `refs/waggle/claims/ticket-007`; a lease whose `TicketID` does not match its ref). `ListActiveLeases` returns the valid leases plus a `*MalformedClaimsError` listing each bad ref, with `errors.Is(err, ErrMalformedClaim)`. `AcquireLease` on a malformed target returns `ErrMalformedClaim`.
12. **Local concurrency:** 8 goroutines with separate `GitBackend` values on the same repo race to claim one ticket behind a start barrier. Exactly one returns nil; all others return `ErrAlreadyClaimed`. Repeat for 5 tickets.
13. **Remote concurrency (the core test):** bare `origin`, two clones A and B, each with its own `GitBackend{Remote: "origin"}` and a different `KeeperID`. Both claim the same ticket concurrently behind a barrier. Exactly one wins; the loser gets `ErrAlreadyClaimed`. The origin ref's lease names the winner. Repeat at least 5 times with fresh tickets.
14. **Remote visibility:** A claims `T-010`; B's `ListActiveLeases` sees it; B's overlap check blocks a conflicting claim; A releases; B's next `ListActiveLeases` no longer sees it (fetch `--prune` works); B's release of a ticket A owns returns `ErrNotOwner`.
15. **Remote expiry takeover:** with a shared fake clock, B takes over A's expired claim by CAS; the origin ref's commit parent equals A's commit.
16. **Relay mode:** all three methods return `ErrRelayNotImplemented`.
17. **Options validation:** remote `-oops`, `origin;rm`, and an unknown `CombMode` are rejected by `NewGitBackend`.
18. **Renderer golden:** a fixed lease set (unsorted input, one expired lease, one with a `|` in a field, multiple directories) renders byte-for-byte to `testdata/workplan.golden`. Rendering twice yields identical bytes; the input slice order is unchanged afterwards. Empty input renders the `_No active claims._` form (assert inline). Support `-update` flag to regenerate the golden file.
19. **WriteWorkplan:** writes into `t.TempDir()`; content equals `RenderWorkplan`; no `.WORKPLAN-*.tmp` files remain; overwriting an existing file works.
