## 4. Input format (decision: JSON file only, no per-field flags)

Options and tickets are lists; flags for lists are error-prone and hard to quote safely in a shell. One JSON object per call:

```
waggle decide --file <path | -> [--repo <dir>] [--dry-run]
```

- `--file` (required): path to the JSON input, or `-` for stdin.
- `--repo` (default `.`): hive root. Must contain a `.waggle/` directory, else exit 1 with `not a waggle hive`. The target is `<repo>/DECISIONS.md`.
- `--dry-run`: validate, assign the next ID, print the rendered entry to stdout, write nothing.
- There is **no** `--date`, `--id`, `--edit`, or `--delete` flag. The date always comes from the system clock; the ID is always assigned.
- Exit codes: `0` recorded (prints `recorded D-007 in DECISIONS.md`), `1` validation, integrity, or I/O failure (message on stderr, nothing written), `2` usage error. Use `flag.NewFlagSet("decide", flag.ContinueOnError)`; `runDecide` never calls `os.Exit`.

### 4.1 Input schema

```json
{
  "kind": "technical",
  "title": "Config parser is a hand-written YAML subset",
  "question": "Which parser reads .waggle/config.yaml?",
  "options": ["A: add a YAML dependency", "B: hand-written subset parser", "C: switch config to JSON"],
  "recommendation": "B",
  "choice": "B: hand-written YAML subset parser, stdlib only, fuzz tested",
  "rationale": "Config is machine-written and tiny; zero dependencies matter more than YAML completeness.",
  "tickets": ["T-004"],
  "supersedes": []
}
```

Decode with `json.Decoder`, `DisallowUnknownFields()`, exactly one object, and reject trailing data (a second `Decode` must return `io.EOF`). Input over 64 KiB is rejected before decoding.

### 4.2 Validation (all failures wrap `ErrInvalidInput` and name the field)

- `kind`: exactly one of `publish`, `spend`, `delete`, `credentials`, `strategy`, `policy`, `technical`, `scope`.
- Text fields and their byte limits: `title` 1..200 (raised from 100 by D-088 so the backfill titles transcribe verbatim), `question` 1..1000, each option 1..500, `recommendation` 1..1000, `choice` 1..1000, `rationale` 1..2000.
- Every text field: valid UTF-8, single line (no `\n`, `\r`), no control characters (including tab and NUL), no leading or trailing whitespace. Rejected, not trimmed: input bytes equal rendered bytes, which keeps round-trip parsing exact.
- `options`: 1..10 entries. `tickets`: 0..20 entries. `supersedes`: 0..10 entries.
- `tickets`: each matches D-003 rules (`^(T-)?[0-9]{1,6}$`, value `>= 1`, uppercase `T-` only). Stored as integers, rendered `T-%03d`, deduped, sorted ascending. Implement as an unexported helper in this package; do not import `internal/comb` (T-002 is unmerged). Add a `// TODO(T-006): unify with comb.ParseTicketID after T-002 merges` comment.
- `supersedes`: each matches `^D-[0-9]{3,}$` canonical (`D-%03d`, no extra leading zeros), refers to an **existing** entry, deduped, sorted. A superseded entry is never modified; the new entry points back to it.

## 5. Rendering (stable, byte-exact)

The whole file is a pure function of the entry list. LF endings, UTF-8, single trailing newline.

```
<!-- SPDX-License-Identifier: MIT-0 -->
<!-- GENERATED FILE: append-only, written by `waggle decide`. Never edit or delete an entry; record a new one that supersedes it. -->
# DECISIONS

## D-001: <title>

- **Date:** 2026-10-17
- **Kind:** technical
- **Tickets:** T-002, T-003
- **Supersedes:** none

**Question:** <question>

**Options considered:**
1. <option 1>
2. <option 2>

**Hive recommendation:** <recommendation>

**Keeper choice:** <choice>

**Rationale:** <rationale>
```

- One blank line between the header and the first entry and between entries. No trailing blank line beyond the final `\n`.
- Empty `tickets` renders `none`; empty `supersedes` renders `none`; non-empty lists join with `, `.
- ID: `D-%03d` (`D-1000` after `D-999`). Date: `now.UTC().Format("2006-01-02")`.
- Text is emitted verbatim. Because every field is single-line and prefixed (`**Question:** `, `1. `), no field can start a line, so no input can forge an `## D-` heading.

### 5.1 Parse

`Parse(data []byte) ([]Entry, error)` reads the exact format above. Integrity rule: `Render(Parse(data)) == data` byte for byte, IDs run `1..n` contiguous, dates are valid `YYYY-MM-DD` and non-decreasing, every `supersedes` points to a lower ID. Any failure returns `ErrCorrupt` with the first offending line number. An empty or missing file is zero entries.

This catches format damage and reordering. It cannot catch a hand edit that keeps the format valid (for example a reworded rationale); that needs git history, see `VerifyAppendOnly` and Q-T006-2.

## 6. Public API

var (

Doc comments on every exported identifier. No `time.Now()` in the package; the CLI passes it.

## 7. Atomic append (behavior of `Append`)

1. `os.Lstat(path)`: if it exists and is not a regular file (symlink, directory), return `ErrCorrupt`. Never follow a symlink out of the repo.
2. Acquire `<path>.lock` with `os.OpenFile(O_CREATE|O_EXCL|O_WRONLY, 0o600)`, write the PID, close. If it exists, return `ErrLocked` naming the lock path and stating it is safe to remove only if no `waggle decide` is running. No automatic stale-lock breaking. Release with `defer os.Remove` on every path.
3. Read the file (cap 4 MiB, else `ErrCorrupt`). Missing file means zero entries and a fresh header.
4. `Parse` (section 5.1); fail on `ErrCorrupt`.
5. Validate input (4.2), including `supersedes` against parsed IDs. Build the entry with ID `len(entries)+1` and today's UTC date. Reject if the date is earlier than the last entry's date (clock went backwards) with `ErrInvalidInput`.
6. `next := old + "\n" + RenderEntry(e)` (or `Render([]Entry{e})` when old is empty). Assert `VerifyAppendOnly(old, next) == nil` as a self-check.
7. `os.CreateTemp(dir, ".DECISIONS-*.tmp")`, write, `Sync`, `Close`, `Chmod 0o644`, `os.Rename` onto `path`, then open the directory and `Sync` it (ignore `EINVAL`/`ENOTSUP` from platforms that do not support directory sync). Remove the temp file on any error. A crash leaves either the old file or the new file, never a partial one.

The command never commits. The resulting `DECISIONS.md` change goes through the normal PR flow (D-017), which is a Full gate because the path is Tier 2 minimum.

## 8. Who runs it (v0.1)

The command cannot verify that a decision was approved. In v0.1 it is run by the Keeper, or by `queen` only after an explicit Keeper answer in the same session. Later `waggled` calls `decisions.Append` when a decision card is answered over `run.sock`. Cells never get this command. State this in the `decide` usage text and the package doc comment.

## 9. Tests

Pure Go, no git, never skip, all files under `t.TempDir()`. Fixed clock values.

1. **Validation table:** every rule in 4.2 has a case asserting `errors.Is(err, ErrInvalidInput)` and the field name in the message: unknown kind, `Technical` (case), empty title, 201-byte title, newline, CR, tab, NUL, leading space, invalid UTF-8, 0 options, 11 options, 21 tickets, ticket `t-1`, `T-0`, `0`, `T-1234567`, supersedes `D-1`, `D-0001`, supersedes a missing ID, unknown JSON field, two JSON objects, input over 64 KiB.
2. **Ticket canonicalization:** `["3","T-002","T-3"]` renders `T-002, T-003`.
3. **First append:** missing file produces header plus `D-001`; content equals `Render` of one entry.
4. **Sequential appends:** three appends yield `D-001..D-003`; after each, `Parse` round-trips and the previous bytes are an exact prefix of the new bytes.
5. **Golden:** the 85 backfill inputs (section 10) appended in order with the clock fixed at `2026-10-17T12:00:00Z` match `testdata/backfill.golden` byte for byte. Support `-update` to regenerate.
6. **Corruption refusal (`ErrCorrupt`, file unchanged):** an entry deleted from the middle (ID gap); two entries swapped; a field line removed; extra blank line; CRLF endings; missing trailing newline; duplicate ID; date going backwards; supersedes pointing forward; `DECISIONS.md` is a symlink; file over 4 MiB.
7. **Append-only verifier:** `VerifyAppendOnly` accepts old+one entry and old+three entries; rejects a changed byte in an old entry, a removed entry, a reordered file, a truncated new entry, and a new entry with a non-contiguous ID.
8. **Lock:** a pre-existing `.lock` returns `ErrLocked` and leaves the file unchanged; after a successful append no `.lock` and no `.DECISIONS-*.tmp` remain.
9. **Concurrency:** 8 goroutines call `Append` on one path behind a start barrier, retrying on `ErrLocked` with a short sleep. Final file parses with exactly `D-001..D-008`, contiguous, no lost entries.
10. **Clock backwards:** last entry dated `2026-10-18`, append at `2026-10-17` returns `ErrInvalidInput`.
11. **CLI (`decide_test.go`):** success prints `recorded D-001 in DECISIONS.md` and exits 0; `--file -` reads stdin; `--dry-run` prints the entry and the file does not exist afterwards; missing `--file` exits 2; repo without `.waggle/` exits 1; invalid input exits 1 and writes nothing; unknown flags `--date`, `--id` exit 2.
