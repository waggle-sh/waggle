## 1. Goal

`docs/multi-keeper.md` section 3 says two claims that collided before the folded rule "keep renewing but never grow or change hands". That reads as if neither claim can add directories. A grandfathered renewal can add any directory that does not collide; only the collision itself cannot grow. Say that exactly.

## 2. Scope

- Reword the sentence so the collision never grows or changes hands, and the claims may still add directories that do not collide.
