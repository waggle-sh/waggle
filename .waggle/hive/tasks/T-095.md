## 1. Goal

About 80 distinct `cmd/...go:NNN` and `internal/...go:NNN` citations sit in the docs. Any edit to a Go file can make them point at the wrong line.

## 2. Scope

- A new `cmd/waggle/docs_citations_test.go` extracts every `path.go:N` and `path.go:N-M` citation from `README.md`, `docs/gate.md`, `docs/nectar.md`, `docs/quorum.md` and `site/content/*.md`, and fails when the file is missing or the line is past the end of the file.
- For each citation preceded by a backticked identifier on the same line (for example `runClaim`), the cited line or the 20 lines before it contain that identifier. Citations without an identifier are only range-checked.
- The audit fixes every citation the test flags by updating the line number to the current one. Prose is not rewritten.
- The test lists all failures at once.

## 3. Checks

`go test -race ./cmd/waggle/...`, vet, gofmt.
