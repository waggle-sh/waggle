## 1. Goal

Make the gate's head tree collision check catch paths that differ only in Unicode normalization. `caseCollisions` (`cmd/waggle/gate_commits.go:399-401`) folds with `strings.ToLower` and `strings.EqualFold` and does not normalize, so a head tree holding `café` in NFC and `café` in NFD passes the gate, while macOS APFS treats them as one name.

## 2. Scope

- Normalize path names before the collision comparison in the gate's head tree check, with tests for NFC against NFD.
- Update `docs/gate.md` where it describes the check.

## 3. Out of scope

- Claim-time overlap checks (T-073). D-037 keeps lease directories ASCII, so claims need no normalization; any ticket that relaxes D-037 must add it (Q-T073-2).

T-073 Q-T073-8, ruled in D-380: the gap is its own ticket with a release, so it stays on the roadmap (vision guard 3) without turning a claim ticket into a gate change.
