## 1. Goal

`ClaimsView` returns one error for the sync and the scan together, and `loadStatus` turns it into exit 3 before any collision result exists. That claims-read failure path of `waggle status` has no test through `runStatus`. The `CollisionsErr` field, its stderr branch in `runStatus` and the `collisionsWarning` helper are unreachable since T-081. Test the live path and remove the dead one.

## 2. Scope

- A test through `runStatus` where the claims read fails (for example, a remote-mode hive whose `forge.remote` points at a missing repository, so the sync fails): exit 3, stderr starts with `waggle status failed:` (git's own message follows and can span several lines), nothing on stdout, and no collision warning on either stream. Checked on main `86fa3a1`: setting `forge.remote: origin` with origin pointing at a missing path gives exactly that.
- Remove `statusData.CollisionsErr`, the `if d.CollisionsErr != nil` branch in `runStatus`, `collisionsWarning` and `TestCollisionsWarning`.
- No golden file changes. The guard checks that `git diff` touches no `*.golden` file.

## 3. Out of scope

- Behavior changes to `waggle status`, its exit codes or its messages.
- `waggle hives status` (T-084).
- `internal/comb`.

## 4. Stop

The new test passes, `go test ./...` and `go vet ./...` pass, the gate is green and no golden changed. If the failure path cannot be reached without a new hook in `internal/comb`, stop and report instead of widening the lease.
