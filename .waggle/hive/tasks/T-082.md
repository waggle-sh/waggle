## 1. Goal

The failed-scan path of `waggle status` is tested only through the `collisionsWarning` helper. Add a test that runs `runStatus` with a collision scan that fails while the claims read succeeds, and checks exit 0 and exactly one stderr warning line.

## 2. Scope

- A test through `runStatus` for the failed scan: exit 0, one stderr line, no collision lines on stdout.
- The smallest hook that makes the scan fail on its own, if one is needed.
