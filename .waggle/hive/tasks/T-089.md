## 1. Goal

README quotes the `claim`, `release` and `force-release` usage lines by hand, and `cli.md` lists every command, with nothing tying either to the source.

## 2. Scope

- A new `cmd/waggle/docs_drift_test.go` runs `claim -h`, `release -h` and `force-release -h` in-process and asserts each `Usage:` line appears verbatim in the README "Writing a claim" block and in `cli.md`.
- Every command word printed by the top-level usage appears as a heading or table row in `cli.md`.
- Every flag in the `nectar`, `vote` and `quorum` rows of `cli.md` exists in that command's `-h` output.
- The test reads files relative to the repo root found by walking up to `go.mod`, and fails with the file and the missing string.
- Any drift it finds is fixed in the docs, not in the code.
