## 1. Goal

`waggle init --claims` writes the `AGENTS.md` section, the claims workflow and the `claims.*`, `priority.*` and `governance.*` config keys (owners commented out, so the admins default applies until a person fills it in), and prints the label to create. No ruleset, no admin step, works on GitHub Free private repos.

## 2. Scope

- Idempotent; refuses to overwrite an edited file.
- `waggle uninstall` removes what it wrote.
