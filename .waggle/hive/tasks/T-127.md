## 1. Goal

One package with no I/O that every entry point shares: the claim record, v1 parse and render, the arbitration rule (earliest valid claim by server time and comment id), expiry with grace, claim id matching, path normalization and overlap, and the tracker-neutral `Tracker` interface the adapters implement (GitHub in Level 1, Linear in T-129 after the dogfood, D-412).

## 2. Scope

- Parse and render v1 blocks; reject malformed blocks with a reason; caps on sizes.
- `Arbitrate(comments, now, mayClaim)` returns the holder and the losers.
- No GitHub type in the package; "may this author claim" is an adapter method.
- Overlap across claims reusing `comb.NormalizeDirectories` and the folded overlap rule.
- The `Tracker` interface (list, comments, post, edit, assign, label, permission, server time, admins, and the priority and priority-change reads T-142 implements).

## 3. Out of scope

- Any network call. Changes to `internal/comb`.
