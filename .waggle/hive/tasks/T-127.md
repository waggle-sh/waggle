## 1. Goal

A pure package with no git or network: everything that decides a claim, testable from data alone.

## 2. Scope

- Key rules for each source (T-124 section 4.1): lower case, the safe character set, length cap, the `h-` hash fallback, and the hive `ticket-<n>` form.
- `claim.json` v1 parse and render with caps on every field; the hive `lease.json` read through comb's exported decoder.
- Liveness: `expires_at`, the 10-minute grace and the 24-hour read-side cap.
- Overlap: a live hive `ticket-<n>` lease always wins; between new-kind claims, earliest wins (`scoped_at`, then key). Reuses comb's path normalizer read-only.
- The holder cap and the bucketed priority comparison used by `next`.

## 3. Out of scope

- Refs and pushes (T-145). Reading sources (T-142). Any issue API (T-128).
