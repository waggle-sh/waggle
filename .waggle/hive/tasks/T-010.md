## 1. Goal

The project's GitHub home is the `waggle-sh` organization, repo `waggle-sh/waggle` (D-024; `waggle-dev` belongs to an unrelated user account). The Go module path must match the repo so `go install github.com/waggle-sh/waggle/cmd/waggle@<version>` works once the repo is public (D-025). Change `module github.com/waggle-dev/waggle` to `module github.com/waggle-sh/waggle` and update every reference. No behavior change.
