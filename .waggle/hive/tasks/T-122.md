## 1. Goal

`gate verify` encodes newline and carriage return in a finding line, but prints a tab and a backslash raw. A path with a tab can make a finding line read as two columns, and a backslash makes the encoding ambiguous. Encode both, the same way newline and CR are encoded.

## 2. Scope

- The finding encoder writes a tab and a backslash in its escaped form, in plain and GitHub Actions output.
- `TestPathsAwkwardOutsideClaim` (T-093) is updated to the new text, and its "no raw control byte" check covers tab as well as CR.
- `TestVerifyEncodesHostileText` keeps passing.

## 3. Out of scope

- Changing which paths pass or fail.
