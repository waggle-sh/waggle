## 7. Threat model (D-203, scaled to docs)

**Harm:** a reader who believes the gate enforces something it does not, and lets agents loose on that belief. Secondary: copy-paste YAML or commands from the docs that weaken the reader's repo, and claims about other tools that are false or read as endorsement.

**Attacker:** none in the usual sense; the "attacker" is the error a reader will copy. The PR author of this ticket controls only the docs; the docs control no code.

**Must-fix:** an enforcement claim without a citation, or stronger than its code (for example "prevents", "blocks agents from", "guarantees", where the code fails a check on a PR that must pass it); a missing precondition (required check, PRs required, `fetch-depth: 0`, claim refs fetched, the review trigger, `pull-requests: read` and the token in the gate step, code-owner review on workflows); a 3.2 limit or bypass left out of `docs/gate.md`; a recipe telling the agent to write its own claim, handing it approver credentials, or advising `pull_request_target`, a write permission, or `${{ }}` interpolation of PR-controlled fields into `run:`; any YAML not copied from merged files; an invented SHA, tag, flag, input or output line; a claim about another tool not backed by a verified section 4 row; another project's branding, or wording that implies endorsement; a bee name or decision ID in README, `docs/gate.md` or `docs/recipes/**` outside a literal code span; files outside the lease rule.

**Note, not must-fix:** style, ordering, length within budget, a citation off by a few lines that still names the right function.

**Guard prompt sentence (repeat verbatim):** "Threat bar (D-203), docs: must-fix is any statement a reader could rely on that the cited code does not do, any missing precondition or known bypass, any copied command or YAML that weakens a repo or is not from merged files, any claim about another tool not backed by a verified section 4 row, any bee name in user-facing docs outside a literal code span, and files outside the lease rule; style and wording choices are notes."
