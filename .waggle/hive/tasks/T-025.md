## 4. Header rules (C2 implements, C1 and phase B apply)

One line, `SPDX-License-Identifier: <id>`, in the file's own comment syntax, on line 1 (line 2 after a `#!` shebang). Go files put a blank line after it so it never becomes the package doc comment. In a Go file that starts with `//go:build`, the header goes above it with the blank line between; a build constraint may follow other line comments and blank lines, so the constraint still applies. No copyright line per file (Q-T025-1).

Form by extension: `.go`: `// `; `.sh`: `# ` after the shebang; `.yml`, `.yaml`, `.yml.tmpl`, `.yaml.tmpl` and `CODEOWNERS`: `# `; `.md`, `.md.tmpl`: `<!-- ... -->`. A checked path with any other extension is an error (a new kind of file gets a form on purpose).

## 7. Phase D: DCO enforcement (Tier 3)

Recommended (Q-T025-4, D-131): a `dco` job in product CI, required by the `main` ruleset. Draft for the Head Keeper:

```yaml
  dco:
    name: dco
    if: github.event_name == 'pull_request'
    runs-on: ubuntu-latest
    timeout-minutes: 5
    steps:
      - uses: actions/checkout@v5
        with:
          fetch-depth: 0
          persist-credentials: false
      - name: Signed-off-by on every PR commit
        env:
          BASE: ${{ github.event.pull_request.base.sha }}
          HEAD: ${{ github.event.pull_request.head.sha }}
        run: |
          fail=0
          for c in $(git rev-list "$BASE..$HEAD"); do
            email="$(git log -1 --format=%ae "$c")"
            if ! git log -1 --format='%(trailers:key=Signed-off-by,valueonly)' "$c" | grep -qiF "<$email>"; then
              echo "::error::$(git log -1 --format='%h %s' "$c"): no Signed-off-by for <$email>"
              fail=1
            fi
          done
          exit "$fail"
```

- Merge commits inside the PR are checked like any other (Q-T025-6). The merge commit `gh pr merge --merge --admin` creates on `main` is outside the PR range and not checked.
- Event values reach the script through `env`, never inline `${{ }}` in `run`.
- Then the Head Keeper adds `dco` to the ruleset's required checks next to `product-ci` and `verify-leases-and-tiers`, and reads it back (as D-098). That changes the D-098 record, so the queen logs it with `waggle decide`.
