## 1. Goal

Give the CLI (and later `waggled`) one function that reads `.waggle/config.yaml` and returns a validated `comb.Options`, so `waggle claim` / `waggle release` / `waggle status` wiring never hand-parses config. Map:

| Config key | `comb.Options` field | Notes |
| :--- | :--- | :--- |
| `forge.comb_mode` | `CombMode` | `direct` or `relay`. |
| `leases.default_ttl_minutes` | `DefaultTTL` | minutes to `time.Duration`. |
| `leases.max_directories_per_claim` | `MaxDirectoriesPerClaim` | int. |
| `forge.remote` (D-007) | `Remote` | Absent or `""` means local-only (Scale = 1). No `--remote` CLI override. |
| (caller argument) | `RepoDir` | Not in config. Passed by the caller. |

`Now`, `GitBinary`, and `ExtraEnv` are not config. They stay zero-valued from config and are set by callers or tests.

## 2. Background

- The module is Go 1.23, **standard library only** today. There is no YAML parser in the tree. `internal/runtime/AdapterConfig` already carries `yaml:` struct tags, but nothing reads them.
- `.waggle/config.yaml` is a **Tier 3** file (`.waggle/**`). Reading it is fine. This task must not edit it or its template.
- RFC-0003 section 3.4 shows the config as YAML, so the file format is part of the frozen RFC.
- Adding a dependency is Tier 3; D-006 avoids that by keeping the parser in-tree and stdlib only.
- Today's config has **no remote key**. D-007 adds `forge.remote` via a separate Head Keeper edit; parse it whether or not it is present.
- `forge.merge_strategy` is a known key with two values (D-064, D-071): `up_to_date` (the default: a branch must be up to date with main and pass `waggle gate` before merge) and `native_queue` (opt-in, the forge's own merge queue). Today's template and our hive's config still say `native_queue`; T-011 phase A (or its follow-up) changes the template default to `up_to_date`. Parse and accept both, do not map either.

## 3. Requirements

### 3.1 Public API (suggested names)

```go
// Config is the typed subset of .waggle/config.yaml that Waggle consumes in v0.1.
type Config struct {
    Version int
    Forge   ForgeConfig
    Leases  LeasesConfig
}
type ForgeConfig struct {
    Provider      string // "github" or "none" (D-067, T-018)
    CombMode      string // "direct" | "relay"
    Remote        string // forge.remote (D-007); "" means local-only
    MergeStrategy string // "up_to_date" (default) or "native_queue"; parsed, not mapped
}
type LeasesConfig struct {
    DefaultTTLMinutes      int
    MaxDirectoriesPerClaim int
}

// Load reads and parses path (normally <repo>/.waggle/config.yaml).
func Load(path string) (*Config, error)
// Parse parses config bytes. Pure: no filesystem, no env, no clock.
func Parse(data []byte) (*Config, error)
// CombOptions maps a validated Config into comb.Options for repoDir.
func (c *Config) CombOptions(repoDir string) (comb.Options, error)

var ErrInvalidConfig = errors.New("config: invalid .waggle/config.yaml")
```

`runtimes`, `cell`, `daemon`, and `hive` sections are **parsed for well-formedness but not mapped** in this task. Do not add fields for them unless needed to parse; a later task maps `runtimes` into `runtime.AdapterConfig`.

### 3.2 Validation (all failures wrap `ErrInvalidConfig` with the key path and, where available, the line number)

- File size cap: reject files larger than 64 KiB before parsing.
- `version` must be present and equal `1`.
- `forge.comb_mode`: absent means `direct`; otherwise exactly `direct` or `relay`.
- `forge.provider`: absent means `github`. `github` and `none` are accepted (`none` is a hive with no code host behind it, D-067, T-018); any other value is an error in v0.1 (D-069).
- `leases.default_ttl_minutes`: absent means 120. Present must be an integer in `1..10080` (7 days). `0`, negatives, floats, and strings are errors. Do **not** rely on the T-002 "<= 0 means default" behavior; an explicit bad value must fail loudly.
- `leases.max_directories_per_claim`: absent means 5. Present must be an integer in `1..64`.
- `forge.remote` (D-007): absent or `""` means local-only. Present must match the T-002 remote pattern `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`. Validate here **and** let `NewGitBackend` validate again; never pass an unvalidated string.
- `forge.merge_strategy`: absent means `up_to_date` (D-064, D-071). Present must be exactly `up_to_date` or `native_queue`; any other value, including a case variant, is an error.
- **Unknown keys inside `forge` and `leases` are errors** (a typo like `default_ttl_minute` must not silently fall back to 120). Unknown top-level sections are allowed and ignored, so future sections do not break old binaries.
- Duplicate keys at any level are errors.
- `CombOptions` returns an error if `repoDir` is empty. It calls `comb.NewGitBackend` in tests only, not in production code (keep the mapping pure).

### 3.3 Mapping

`CombOptions` sets exactly: `RepoDir`, `Remote`, `CombMode`, `MaxDirectoriesPerClaim`, `DefaultTTL` (`time.Duration(min) * time.Minute`). Every other field stays zero. If T-002 merged with different `Options` field names, follow the merged names and note the difference in the PR.

## 4. Parser: hand-written YAML subset, stdlib only, fuzz tested (D-006)

New file `yaml_subset.go` (or `parse.go`) in `internal/config/`. Supported grammar, nothing more:

- UTF-8 text, LF or CRLF line endings. Optional UTF-8 BOM is rejected.
- Full-line comments (`# ...`) and trailing comments (`value # comment`, where `#` is preceded by whitespace and not inside quotes). Blank lines.
- Block mappings only, nested by indentation of **spaces** (tabs anywhere in indentation are an error). Indentation must increase for a child mapping and return to a previously used level when dedenting.
- Keys: `[A-Za-z0-9_.-]+` followed by `:`, then either end of line (child mapping follows) or one space and a scalar.
- Scalars: plain (unquoted, trimmed), double-quoted with escapes `\"` `\\` `\n` `\t` only, single-quoted with `''` as the only escape. Integers are base-10 `-?[0-9]+`. Booleans are exactly `true` / `false` (parse into a raw string; conversion is by the typed mapper).
- **Rejected with a line-numbered error** (fail closed): sequences (`- item`, `[a, b]`), flow mappings (`{}`), anchors (`&`), aliases (`*`), tags (`!`), block scalars (`|`, `>`), multi-document markers (`---`, `...`), merge keys (`<<`), duplicate keys, keys with no value and no children.
- Output: a tree of `map[string]node` with each node carrying its line number, then a typed mapper builds `Config`. Map iteration order must not affect errors (sort keys before reporting so error text is deterministic).
- Size: target under 300 lines of non-test code.
- Required extra test: a Go native fuzz test (`FuzzParse`) that asserts no panic and no infinite loop on arbitrary input, with a seed corpus of the real template plus every rejection case. Guard runs it for at least 60 seconds (`go test -run=^$ -fuzz=FuzzParse -fuzztime=60s ./internal/config/`).
- Cost: we own a parser. It will reject valid YAML that a user writes by hand (for example a list). Acceptable in v0.1 because `waggle init` is the only writer and errors name the line.

## 5. Tests

All tests are pure (no git) and never skip. Tests write only under `t.TempDir()`.

1. **Real template:** read `internal/scaffold/templates/config.yaml.tmpl` (read-only, via a relative path from the package dir), replace `{{PROFILE}}`, `{{DELIVERY}}`, `{{FORGE}}`, `{{COMB_MODE}}`, `{{RUNTIME}}` with `cli`, `installed`, `github`, `direct`, `claude-code`, parse, and assert the mapped values (`direct`, 120 minutes, 5). Repeat with `{{COMB_MODE}}` = `relay`. This catches drift between the template and the parser.
2. **Repo config:** parse `../../.waggle/config.yaml` read-only and assert it loads. (If the Cell does not mount it, skip with a clear message; this is the only test allowed to skip.)
3. **Defaults:** a minimal file `version: 1` maps to `direct`, 120m, 5, remote `""`, and parses `MergeStrategy` as `up_to_date` and `Provider` as `github`. A file with `forge.remote: origin` maps `Remote` to `origin`; `forge.merge_strategy: up_to_date` and `forge.merge_strategy: native_queue` are each accepted and parsed as written; `forge.provider: none` is accepted.
4. **Mapping table:** TTL 1, 90, 10080; max dirs 1, 64; comb mode both values; `DefaultTTL` equals `N * time.Minute` exactly.
5. **Rejections table (each asserts `errors.Is(err, ErrInvalidConfig)` and that the message names the key):** missing `version`; `version: 2`; `comb_mode: Direct`; `comb_mode: push`; `provider: gitlab`; TTL `0`, `-5`, `10081`, `1.5`, `"120"` (quoted string), `abc`; max dirs `0`, `65`; remote `-oops`, `origin;rm`, a 65-char name; `merge_strategy: squash`; `merge_strategy: Up_To_Date`; `merge_strategy: ""`; unknown key `leases.default_ttl_minute`; duplicate `leases:` section; duplicate key inside `leases`; file over 64 KiB.
6. **Unknown top-level section** (`future_feature:` with a nested block mapping `nested: 1`) is accepted and ignored.
7. **`CombOptions`:** empty `repoDir` errors; result passes `comb.NewGitBackend` without error for both comb modes; `Now`, `GitBinary`, `ExtraEnv` are zero.
8. **Determinism:** parsing the same bytes twice yields equal structs and identical error strings for invalid input.
9. **Parser rejections:** every rejected construct in section 4 has a table case asserting a line-numbered error; `FuzzParse` exists with seeds.
