## 1. Goal

Default new installs to `guard`. `open` and `watch` are opt-in through `--mode` or an explicit init question, and `waggle init` uses `guard` when it cannot ask (D-382). Document the modes in plain terms (open, watched and guarded hive) and update CONTRIBUTING terms.

## 2. Scope

- Scaffold default, the init prompt or `--mode` flag, docs and CONTRIBUTING terms.
- Tests for the default and for the explicit opt-in.

## 3. Out of scope

- Verify behavior (T-076). `watch` reporting (T-077). `status` (T-078). `guard`/`open` CLI (T-079).
