## 1. Goal

A stdio MCP server exposing `claim`, `release`, `heartbeat`, `next`, `list` and `show`, using the caller's own `gh` token (a Linear key comes with T-129, D-412), heartbeating held claims while the client is connected.

## 2. Scope

- Issue text returned as capped, labeled fields.
- `claims.max_active_per_lead` enforced.
- Prefer a small hand-written JSON-RPC loop; any `go.mod` change is a Tier 3 card.

## 3. Out of scope

- A hosted endpoint. Tools that edit others' claims.
